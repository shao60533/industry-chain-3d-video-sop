# 《奇点》学习与 Blender 镜头制作手册

版本 singularity-study-1，2026-10-18。用于后续产业链视频的3D镜头，补充现行制作SOP、视觉工程节点和材质与布光校准。以下“项目做法”是我们根据官方资料和抽帧分析形成的执行方法；只有标为“官方说明”的内容归于 Blender Studio。学习目标是提高讲解镜头的完成度，而不是把系列整体改成水彩动画。

## 1. 学习依据与适用边界

官方影片是 Blender Studio 的 [SINGULARITY — Painterly Space Adventure](https://video.blender.org/videos/watch/1ba07bbb-1456-4293-99a6-833fa450eda0)，导演 Andy Goralczyk。[项目主页](https://studio.blender.org/projects/singularity/)说明其水彩视觉、Geometry Nodes群体动画、角色on 2s与环境/特效on 1s、4K HDR方向。学习材料还包括[官方制作花絮](https://video.blender.org/videos/watch/c163ae1a-0bb4-4a91-bd66-e14e131e07bb)和下文列出的公开制作文章/日志。

本章依据公开制作资料与成片/花絮抽帧研究整理。抽帧支持构图、结构与层次观察，不能证明连续运动或混音听感；没有获取并拆解官方生产.blend，受限合成/HDR文章及完整演讲未读完，不声称已经复刻其节点或渲染效果。仓库仅提供方法与来源链接，不分发官方视频、抽帧或受限素材。

本文实现基线为 Blender 4.5 LTS，实际制作须记录本机准确版本。官方项目涉及5.x开发版本；这里的父子控制、关键帧、材质节点、Geometry Nodes实例、View Layer和图像序列采用4.5可实现的基础路径。5.x的VSE合成节点、HDR输出、纹理缓存必须核具体版本能力后再用，不为学习升级在途工程。

直接迁移：先预演后精修、明确的视线引导、空间方向、主次分工、资产复用、材质与灯光联调、分层合成和镜头级验证。

按目的另测：笔触、非写实表面、逐两帧角色动画、夸张辉光、极端广角、HDR。工业产品默认保持成熟产品结构、连续动作和现有竖屏SDR交付；水彩笔触不是解决金属塑料感的通用补丁。保留本期已接受的音色、字幕/标注、产品形状、开场动作及音乐方向。

## 2. 从具体画面学什么

时间来自上述391秒官方视频，定位为抽帧观察点，不是精确镜头切点或节拍测量。电影横幅构图要为9:16重新设计，不能直接居中裁切。

| 官方画面观察 | 可迁移的判断 | 我们的执行动作 |
|---|---|---|
| 00:22、00:29、00:36：冰带从环境进入主角所在局部；00:36黄紫主角在冷色大形体中突出 | 复杂度可以很高，但注意力必须明确 | 产品总览先建立位置；进入技术段时降低周边对比，把亮度/色彩/标注集中到当前功能件 |
| 00:50、00:57：小主角与巨大生物同框，大小和视线提供尺度关系 | 近景需要整体参照，巨大感不靠无限拉广角 | 整机→开盖→局部→接触面；近景前保留上一层结构或给一次回望，不用无依据尺寸标注造真实 |
| 01:11、01:32、02:00：黑色几何边界与有机冰块轮廓相差很大 | 形状语言也能区分类别 | 机械壳体、板卡、管路、线缆分别建立轮廓和尺度；不要每种资产都由同一种圆角盒子替代 |
| 02:07、02:35：主角被相对简化的暖色区域承托 | 留白可形成观看窗口 | 在功能近景给部件及标签留出干净区域；先降背景复杂度，再考虑加字重或加描边 |
| 02:49、03:10、03:17：整体、局部和极近细节有不同信息密度 | 同一模型需要不同观察尺度 | 全景看装配，局部看连接，微距看工艺；不把全片做成同距离的产品转台 |
| 03:59、04:13：群体收束形成一个大形状，亮区成为事件中心 | 群体应组织成可读关系 | 流程/能量示意用少量有源有终点的路径，先形成方向，再增加粒子；禁止用粒子数量代替机制 |
| 05:16、05:23、05:30：由星球到水域再回到主角，整体结果落回具体主体 | 结尾应兑现前文问题并返回对象 | 回到开场产品/关键卡点，同序回答；不是公司名单说完就突然结束 |
| 花絮02:00的ice belt iterations、11:10的tendril/energy fx iterations | 屏幕可见多版实验，不能由此推断完整节点 | 我们也保留同机位对照和明确修改理由，而不是只留“最新最好看”一张图 |

以上关于视线、信息密度和产业链迁移属于本项目分析；不据截图断言官方用了某盏灯、某个shader或某条相机曲线。

## 3. 先导演，再精模：将预演接入B/C

[官方故事流程](https://studio.blender.org/blog/the-story-process-of-singularity/)公开说明：逐镜头文字、缩略图、时间线、低成本3D预演逐步推进；保留空间一致性和可复用相机，维护逐镜头资产拆解。官方还强调持续控制角色、机位和场景数量。我们据此采用以下工作顺序。

1. 从当前批准稿提取“观众在此处应看懂的变化”，一镜只承担一个主判断。例如“热量怎样从芯片进入冷却液”，而非“液冷很先进”。
2. 每镜在既有film-plan/visual_contract内写：口播原句、起止时点、主对象、起始已知关系、新信息、构图、动作、停稳、出镜交接。公司数据段可采用图表/实物静稳镜头，不强造机械动作。
3. 用盒子/低模、原生相机与临时声音排出完整animatic，先检查全片解释顺序、景别重复、空间方向和阅读时长。低模只能通过路线预演，不能充当真实产品成品。
4. 选一个代表性难镜做接近成片的lookdev：同时有金属/黑色/透明件、开盖或拆解、移动相机、标注与两行字幕。完成现有15–30秒连续难例样片，再投入大量精模/长渲染。
5. 精模从镜头需求倒推：先主轮廓、关键装配和讲解件，再做近景会暴露的接口、紧固和材料；装饰和远处重复件最后处理。

预演空间与正式装配尽量一致。改世界尺度、部件位置或相机传感器后，应重新检查全部受影响镜头、纹理尺度、照明和标签投影。不要用预演中“穿壳才能拍到”的机位作为已完成方案。

## 4. 建模：把细节做在功能与尺度上

以下为工业产品项目做法，非《奇点》官方硬表面配方。

| 层级 | Blender里做什么 | 看什么才算有效 |
|---|---|---|
| 主形与比例 | 按产品资料建立壳体厚度、主曲面、开口、正背/维护面；设统一单位和装配原点 | 200/390宽能辨认对象；同机位对照能指出采用了哪些参考特征 |
| 装配与制造 | 盖板接缝、螺柱/卡扣、支撑、安装耳、线缆出入口、插接方向；内部有空腔和真实连接落点 | 闭合、开盖、最大展开、观察近景、合体均成立；不可见面也不能造成穿插 |
| 中尺度细节 | 散热鳍片、PCB分区、接口锁扣、密封边、加工槽、线束固定；重复件实例化 | 细节有功能、疏密和材料差异；不以满板随机小盒子假装真实PCB |
| 近景细节 | 只给已规划近景做必要倒角、焊端、微表面和接触结构 | 最终编码仍可见、不会闪烁；不做比像素还细的噪声来证明精度 |

操作要点：倒角宽度按现实边缘与最终投影决定，先核对象Scale与修改器顺序；不能一键对所有件用同一宽度。平滑法线处理不能替代缺失曲率，Weighted Normal也不能修复薄壳、错误接缝或真实硬边。Boolean后检查斜视高光、法线和近景轮廓；不要只看正视黏土图。需要贴图的部件核UV和方向；保留可编辑的主几何、稳定命名与组件语义ID。

建模退出至少保留闭合/开盖/内部/最大展开/复位五态图和一个功能近景。增加面数、对象数或4K尺寸都不是美术通过证据。

## 5. 绑定与动作：先保证机械关系，再调节奏

花絮可见角色控制器；官方公开日志描述先用影片所需关键姿态测试rig，再继续动画。对应工业片：用实际开盖、插接、维护和合体姿态测试控制系统，不能只证明对象会移动。[官方rig测试日志](https://studio.blender.org/projects/singularity/production-log/318/)

- 每个装配有稳定assembly_root；每个可拆部件有本地原点、语义ID、闭合基准矩阵和明确运动轴。铰链在铰链处转，滑轨沿轨道移，旋钮绕轴转；金属刚体不做角色式挤压拉伸。
- 用父级Empty/控制属性管理大动作，单件保留局部修正。装配移动、爆炸偏移、功能动作分层，避免每段重写所有对象坐标。
- 动作按“让开→展开→停稳看清→功能演示→复位”分相。盖板、线缆、内部件允许错峰，必须保持因果顺序；不可把所有物体同时线性飞散当拆解。
- 设关键帧前捕获原始矩阵/姿态；逐帧求值时避免从上一帧结果继续叠偏移。闭合末帧与基准矩阵核对，保存后重开再验，避免脚本运行成功但工程关键帧丢失。
- 在Graph Editor核慢入慢出、转折与停稳。不能每个短镜头都重复“加速—刹停—再加速”；长动作之间保留连续速度，阅读窗口则有目的停稳。以实际编码观看决定节奏。
- 刚性部件默认连续逐帧运动；官方角色on 2s是风格选择，不套到产品环绕、字幕、引线或流体，避免误把抽动当手工质感。

## 6. 摄影与剪辑：每次移动都要带来新信息

将现有“靠近→打开→原位置探近→停稳→有理由交接”落实为相机控制。可从`camera_root`（世界移动）、`boom`（角度/距离）、`aim`（关注对象）、Camera（焦段/景深）分层；简单镜头可减少层级，不强制安装官方rig插件。

| 讲解任务 | 机位/动作 | 失败例与处理 |
|---|---|---|
| 建立对象 | 3/4总览，展示正面和可进入的维护面 | 产品太小或标签太多：先改变占画面比例和构图 |
| 解释层级 | 沿真实拆解方向展开，侧透视看层间距；停在能对应连接的位置 | 纯正视层重叠：调机位和层距，不能只加轮廓光 |
| 解释内部件 | 盖板先让开，再推近或匹配切到内件；保留参照边缘 | 穿壳/穿管：改路径或切镜，不隐藏实体后冒称可见维护路线 |
| 解释连接/工艺 | 沿真实接口或功能路径交接，近景停稳 | 乱绕找焦点：先定焦点和接触面，再求相机路径 |
| 商业判断 | 使用稳定产品背景/确定性图表，给数字阅读窗口 | 为动而持续摆镜：停稳或换有信息的景别 |
| 回到全局 | 从局部退回或以已建立方向匹配切回整体 | 每段空间重置：修方向、参照与标签交接 |

先确定传感器、输出比例、产品屏幕占比，再选择焦段和距离。焦段变化与相机推进会产生不同透视，不能只靠改焦段代替靠近。微距景深以接触面、接口和当前讲解件可读为准；不要用虚化掩盖建模不足。近裁剪面、最大展开边缘、上下安全区和模型遮挡都在极值机位核。

同一段保持运动方向与部件位置认知；换边前用总览/中性机位交代。官方故事文章明确使用稳定逃离方向组织追逐，我们借鉴方向连续性，不强制全片只从左往右。匹配切镜可连接不同景别；不以“必须一镜到底”逼出不可能路线。

相机朝向与滚转分别控制。跟随目标经过极点时核翻滚/跳变；Track To的上下轴配置不是丝滑保证，必要时改路径、分段或使用Damped Track并单独管理roll。[Blender追踪约束说明](https://docs.blender.org/manual/en/latest/animation/constraints/tracking/track_to.html)

## 7. 材质、灯光与色彩：共同决定表面

《奇点》的冷环境与黄紫主角、暖色能量有明确区分；这是画面分析，不代表工业产品必须使用这些颜色。官方日志也记录着色更新后反复调整灯光：[着色与灯光联调](https://studio.blender.org/projects/singularity/production-log/344/)。本项目继续按[材质与布光校准](material-lighting-calibration.md)执行。

1. **表面角色先行。** 对实际可见表面区分裸金属、喷漆/氧化层、工程塑料、橡胶、玻璃/树脂、PCB/焊料；同色也应有不同反射形态。沿用参考依据，不把Metallic=1当通用真实按钮。
2. **先中性环境诊断，再放回镜头。** 保存原版；固定相机、曝光、采样和显示变换，比较原版/改灯/改材质/组合四组。确认输入是否被贴图接管，记录实际节点，不只记面板默认值。
3. **反射需要可见的环境。** 大软光负责形体，受控条光描边/展示曲率，背景与遮光形状塑造反射层次；黑世界里的金属即使参数正确也可能读不出形体。不是每面都打亮，更不是每件都加发光。
4. **每个尺度重设灯光。** 整机与厘米级接口需要不同距离/面积/角度；核功能表面高光、接触阴影、暗部和玻璃内部，不把整机灯原封不动搬进微距。
5. **尺度与坐标稳定。** 微纹理按工艺、物理尺度和观察距离控制，数据图用正确色彩空间；随对象移动时纹理不能游泳。Generated是归一化坐标，不能冒称米制加工纹理。
6. **有整体色彩计划。** 冷暖、背景亮度和强调色按章节/功能保持一致，品牌/产品颜色有依据。使用value/灰度对照判断焦点，不能让最亮的装饰抢走讲解件。
7. **一个镜头一个完成目标。** 先解决轮廓、功能面和材料分离，再增加微表面；高光剪白、黑色融背景、玻璃成黑板、反射忽明忽暗都退回修。

不把“更暗、更锐、更饱和、更多划痕”当统一提升。材质或显示变换改变后，重看所有受影响景别与相邻镜头，而不只看单张封面。

## 8. Geometry Nodes与特效：服务重复结构和功能关系

官方项目说明把Geometry Nodes用于群体行为，制作日志列出沿曲线运动与序列缓存实验：[程序化运动记录](https://studio.blender.org/projects/singularity/production-logs/?page=6)。我们采用实例化与稳定控制思路，不据此声称拿到了官方群集节点树。

- 适合程序化：鳍片、紧固件、重复电池单元、规则器件、线束候选路径、非定量的功能示意流。先建有依据的母件，再实例化；随机变化限制在真实允许范围。
- 重复组件保留稳定ID和seed；不要让随机值随每帧重抽。缓存记录起止帧、版本和依赖；修改源几何/节点后重新烘焙，不能拿旧cache验新模型。
- 连线/管路有起点、终点、方向、弯曲半径和固定关系；进入接口并贯通的功能要实际成立。示意流沿确认路径移动，盖板拆开后不切断原本应相连的关系。
- 实例若要用于产品标注，需能从求值结果定位到对应组件/表面。无法可靠求值时为讲解主体保留独立对象或稳定锚点，不用屏幕手填坐标掩盖漂移。
- 只在需要独立编辑、导出或运算时Realize Instances，先测内存和求值时间，避免为“真实”把全部重复件展开成重网格。
- 发光、流线、粒子必须说明“示意”，不虚构测量温度、光路、流速、电流或厂商内部布局。无数据时不画定量梯度/比例。
- 特效前后对照：关闭特效仍能识别结构；打开后没有遮住讲解接触面。glow只扩展亮区，不能把错误接线或低完成度模型洗成光团。

水彩笔触/Brushstroke Tools仅作为另行获选的风格实验。[官方工具文档](https://studio.blender.org/tools/addons/brushstroke_tools)描述变形表面的稳定附着；未安装实测前，不承诺在本机/任意模型上即用。硬表面写实产品不强行加笔触。

## 9. 合成、调色与文字：保留可修改的边界

官方公开日志记录了最终渲染后继续做合成、色彩连续性和闪烁修复：[后期制作记录](https://studio.blender.org/projects/singularity/production-logs/?page=2)。受限的《Compositing Colourful Critters》仅核到标题/介绍，不能用它证明我们掌握了其具体合成节点。以下为项目的可执行方案。

- 保留线性渲染的足够位深；需要后期重调时用经本机验证的OpenEXR图像序列。原始beauty保留，按实际需要输出对象/材质遮罩、深度等pass；不为凑层数输出无用数据。
- 产品、必要特效、背景可用Collection/View Layer组织，但要保留接触阴影、遮挡和反射关系；拆层后不出现“漂浮贴纸”。合成开关对照能解释每一步用途。
- 控制glare/bloom、暗角、锐化、景深和运动模糊，逐项查看端口、薄线与小字；不要全片套强烈镜头污渍/色差来营造电影感。
- 曝光、显示变换和编码转换按同一色彩链锁定，不能烘焙两次显示变换。跨镜头先匹配共同产品的明度/颜色和反射，再做局部强调。
- 标题、字幕、数字/单位和公司数据继续确定性合成；产品标注使用原生求值锚点随镜头走，不把文字烘进美术贴图。现有56px、画面中轴、672px行宽、24px间隔与safe profile照常适用。
- 横幅影片的留白不能直接当竖屏安全区。先在9:16重新排产品与文字，再验200/390宽和实际平台界面；工业片讲解段不能借电影留白忽略信息可读性。

## 10. 声音与剪辑节奏

官方故事文章说明临时音乐在预演阶段就参与节奏设计；120 BPM是当时预演的方便选择，最终配乐会再创作。我们采用“前期有节奏依据”，不把它写成《奇点》最终音乐实测BPM，也不变成系列固定速度。

开场先在时间线标实际动作事件：展开开始、最大展开、环绕观察、合体接触、标题进入。根据现有音乐确定主要重拍及过渡；轻whoosh/click/impact只服务动作，不能每个字幕都打音效。

正文以完整语义段落与技术理解优先。观点句、数字、部件显现和停稳阅读共同决定剪辑点；不能为了每拍切镜截断获选旁白、术语或数字单位。章间可降低密度、退回整体再进新功能区；不靠片长倒推统一加速。

混音需检查：获选旁白是否清楚、音乐是否掩盖关键词、连续拼接处是否突变、机械/环境声是否制造错误因果。频谱、响度和波形仅辅助；本次没有实听《奇点》，不从文字宣称掌握其混音参数。原片配乐不直接挪用到商业内容；确需复用时核具体资产许可和署名要求。

## 11. 渲染、工程与交付

[官方渲染估算文章](https://studio.blender.org/blog/estimating-final-render-times-using-blender-vse/)从镜头现有帧元数据提取时间/采样，做近似预算。我们据此按代表镜头实测，不照抄官方耗时、采样数或线性倍率。

- 资产主文件维护结构、语义和材质；镜头文件维护相机、照明和必要override。改公共资产列出受影响镜头，避免每镜复制一份后越改越不一致。链接/override如未验证，先用受控本地副本和明确版本，不能为形式引入复杂插件。
- 记录Blender版本、渲染器/设备、分辨率/百分比、fps、帧段、采样/降噪、色彩配置、外部贴图与缓存。保存可重开的.blend及相对依赖清单。
- 选择亮暗、玻璃、薄线、最大展开、快速运动各类代表帧与短帧段测算；预算包括合成、编码与返工。低采样降噪擦掉接口/造成爬动时，修采样或资产，不用锐化假补。
- 优先图像序列渲染，逐帧确认数量、连续性与失败帧，再组装编码。恢复只补缺帧/坏帧，不把未验证的大文件当完成。
- 对运动模糊和降噪做连续片段检查；静帧高质量不能证明运动时没有闪烁、薄件消失、纹理游泳或辉光跳变。
- 最终按原交付profile核分辨率、帧率、时长、音画同步和四项色彩标记。维持当前SDR路径；[官方5.x开发文章](https://studio.blender.org/blog/blender-development-singularity-and-beyond/)所述HDR能力不等于本机4.5或目标平台已经验过HDR。
- 场景源、图像序列、声音、字幕/标注、最终编码和检查证据分别绑定版本。改几何/相机/材质/光照/色彩链后，使对应后续证据失效，按最早受影响节点重验。

## 13. 下一次实际制作的练习与准出

以下是待执行练习，不是已完成样片。选下一期真正要讲的一个功能组件，使用其真实资料；不另造产业结论。

做25秒左右可编辑镜头，时间是起步预算，按口播/音乐调整：0–4秒整体定位，4–9秒盖板让开/层级展开，9–14秒沿真实空间靠近并出现产品标注，14–20秒停稳解释一个连接或工艺，20–25秒明确交接或合体返回。对应全片内已有镜头，避免练习完另起一套无关模型。

输出顺序：低模路线预演→一个功能近景lookdev→五态与分项对照→连续编码。难例同时包含至少两种能辨认的材料、一个真实连接、一次相机移动、一次停稳与标签跟随；不以增加无关动作来凑数量。

实际复核必须回答：

1. 不看字幕，能否指出当前讲解件和它连到哪里？
2. 总览与近景是否来自同一装配，盖板/线缆是否按真实关系让开？
3. 灯光是否呈现表面差异，关闭特效后结构是否仍成立？
4. 相机每次移动带来什么信息；是否存在无用横摆、突然重置或穿实体？
5. 最终编码里材料、纹理、薄件、降噪和标签是否稳定，手机宽度是否读得懂？

每项留具体帧段、缺陷、修改理由和复测结果。用另一个不同部件独立复做，才能证明方法具备迁移能力；写完手册与看过参考不等于Blender制作能力已验证。
