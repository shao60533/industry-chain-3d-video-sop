# 产品材质与布光校准

2026-10-14方法校准：产品形状已接受，但整体仍呈塑料感，且同类缺陷跨镜头重复。本条进入现有产品真实性/材料层次观察，不新增第13项报告，不以参数检查自动通过美术。

## 先定位原因，再改参数

保留已接受的几何和机位，保存原工程与原图。导出实际被镜头使用的材质、Principled输入值及连线、纹理坐标/色彩空间、光源位置/面积/功率、世界光与显示变换。改默认值前检查输入是否被贴图接管；隐藏旧对象和未使用材质不能混入结论。分别做原版、照明与环境、产品材质、两者组合的同机位对照，采样/曝光/显示变换保持一致。每次具体判断缺陷发生在哪个表面，不能只写“高级了”。

审视的是实际暴露表面：裸金属、氧化/喷涂层、清漆、树脂、橡胶、玻璃分别决定响应。金属零件覆有漆层时，表面可以是非金属；不能一律把Metallic拉到1。车漆可表现为色料/金属薄片底层与清漆，透明玻璃不额外套无依据的清漆。轮胎、工程塑胶、铸铝、加工铝、焊料应有不同的高光宽度和明暗过渡。

微表面先核尺度与制造方法：Generated坐标按每件包围盒归一化，不是米；同一Noise Scale复制到不同尺寸零件可能完全失真。用明确物理单位/UV密度，并让坐标随部件动画移动。铸造颗粒、加工方向、清漆微起伏和橡胶哑光分别控制；细节要在实际近景中可见，不能靠无限细噪声、过大凹凸或随机划痕证明真实。法线/粗糙度等数据图使用Non-Color，保留有依据的原贴图及UV。

布光按观察对象调整目标、距离、光源形状及面积。主光负责形体，条光负责边缘/反射，补光保留信息；不能全用同样大小的四盏软箱。整车与几厘米内件不能沿用同一远距离场景灯而不校准。按比例缩放光源和距离时，归一化面积光的功率以尺度平方作为维持照度的起点，再实际看片；这是缩放方法，不是固定曝光承诺。色温保持克制，不用强蓝/橙掩盖表面差异。

显示变换与曝光分开诊断。AgX在高曝光区会淡化颜色，先控制照明和反射组织，再判断是否需要改变显示变换。需要时用线性渲染/False Color定位高亮；输出PNG的白像素比例不能证明线性曝光没问题。更暗、更亮、更高对比、更低粗糙度都不自动等于真实。

需要时可用[Light Linking](https://docs.blender.org/manual/en/4.5/render/lights/light_linking.html)约束摄影反射源，但它是美术控制，不称物理光学仿真。最大展开、近景及合体返回时核接收组和临时灯是否正确恢复，不把展开用的玻璃反射限制遗留到闭合镜头；过渡仍需连续编码实看。函数抽取须带齐依赖，静态状态往返检查不能签发运镜丝滑。

## 现有节点里的验收观察

C的产品参考采用/材料层次证明至少附：当前工程SHA、暴露表面角色表、节点/灯光诊断、同机位对照及实际采用理由。用户只接受形状时，记录形状批准的原版本；不扩成材质、完整模型或全片批准。

E的`product_realism_states`，以及原12项`model_coverage`/`cover_crop.material_hierarchy`，实际看闭合、展开、各技术近景与最大视角：金属和塑胶有无可辨差异，高光是否吞掉接口/齿形/焊端，黑色是否吞掉部件，玻璃是否成黑板，表面纹理是否按尺度稳定，背景是否有硬接缝。原尺寸、200/390宽和连续编码分别记范围。静帧修复不能签发动态材质稳定或最终成片通过。

改动材料、灯光、世界光或显示变换，使受影响图、镜头、锚点绑定及最终编码的原证明失效。全期查同类缺陷，重新渲染受影响范围；保留旧版。数值检查是诊断与版本证据，真人或具备看图能力的制作者完成具体观察，真实记self_review；缺乏连续播放能力的项保持pending。

## 官方依据

Principled把Metallic定义为金属/介电模型之间的混合，Coat表达表面涂层，Roughness控制微表面反射分布：[Blender 4.5 Principled](https://docs.blender.org/manual/en/4.5/render/shader_nodes/shader/principled.html)。这些是模型机制，不是某个产品的测量参数。

面积光默认Normalize维持总功率，改变尺寸也会改变光分布：[Blender 4.5 Lights](https://docs.blender.org/manual/en/4.5/render/lights/light_object.html)。Generated坐标在对象包围盒内为0–1：[Texture Coordinate](https://docs.blender.org/manual/en/4.5/render/shader_nodes/input/texture_coordinate.html)。数据图与显示变换须分别处理，AgX保留大动态范围并压缩高亮颜色：[Color Management](https://docs.blender.org/manual/en/4.5/render/color_management.html)。

以上指导用于后续新任务。具体任务在其原固定runtime之外登记获授权的材质校准证据；不替换其固定政策，不补签旧任务，不改已发布影片。文档更新不表示所有历史片都已修复。
