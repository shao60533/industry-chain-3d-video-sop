# 系列视觉质量基准：光模块对标

visual-quality-1.1，2026年10月7日。补充video-2.2制作与验收规则，保持12项检查，不用自动审美分数放行。新增用户“封面不一定和视频内容一样”的独立设计要求。

使用者应选择有权使用的实际封面和成片作为基准，保存版本与SHA。本文保留光模块等产品的质量判断方法，不分发内部成片和对照素材。旧黑底字幕、低位布局和过亮区域不继承。

## Q-B：投入全片前必须看见品质

先完成独立封面设计，以及同源模型的整机闭合/展开图、一个关键内件功能近景和15–30秒连续正文样片。封面可用另设模型机位或独立生成图，不受正片镜头限制；正文仍按真实模型结构检查。将本期图与基准各按200和390px同宽排列；产品类型不同允许不同造型和材料，但主体辨识、功能细节、材料区分与光影完成度须作具体比较。可增加用户指定的半导体等实际封面作为相关产品参照，不以印象替代文件。

参考学习记录必须是「官网原图→该部件→可见设计特征→本期采用/不采用及原因→新版对照」。下载照片、记录网址、对象数、曲壳存在和高清尺寸均不能单独通过。通用教学模型不冒称厂商CAD，仍应具有合理装配和产品完成度。

## 封面在cover_crop中同时验裁切和美术

原有9:16、3:4、200px、360px四项继续保留。再要求下列五个观察ID，每项给当前图、基准对照、具体观察与判定，不以「精美/高级/已看」代替细节：

| ID | 必须回答 | 不通过的实例 |
|---|---|---|
| benchmark_comparison | 比的是哪个实际版本？同宽图中有哪些明确保住/变差的地方？ | 只引用「第一期很好」或错误封面版本 |
| product_readability | 主体是什么？最值得拆的内部结构在哪？200/360px能否认出功能对象？ | 只能看到漂浮白块或很多同样小的零件 |
| material_hierarchy | 主要材料、反射、接触阴影怎样区分？有无高光洗掉细节？ | 所有部件是同一亮面，主要内部件融成白块 |
| cover_narrative | 图怎样兑现「拆开」「谁赚钱/卡脖子」？哪个具体结构是视觉入口？ | 最大展开截图排满零件，却没有主焦点和产品关系 |
| series_typography | 主标题/产品词/悬念/品牌层级是否清楚？和主体怎样配合？ | 长标题挤成同级小字，靠字号可读证明吸引力 |

任何美术项不通过，综合cover_crop不能passed；仅裁切通过要明确它的范围。文字内容保持用户确认版本，不能为追求冲击添加未证数字或厂商供应关系。封面独立组织一个内部主焦点，不默认用开场最大展开帧；可重设模型镜头和灯光，也可使用生成式封面。后者记录工具、实际像素尺寸、来源参考、文字核对与“通用结构示意”身份，不称为实物照片、CAD或工艺剖面证据。提示要求的尺寸不等于实际输出；放大不称原生高清。先内部比较不同取景，交付一个有明确理由的版本；不把挑选责任转给用户。

这些ID放入生产spec的requirements.cover_crop，现有程序会核观察项与证明文件覆盖；具体审美判断仍须实际看图。模板不是实际通过报告。

## 正文必须呈现功能

按口播功能窗口审视输入、传动/转换、输出和反馈。先总览定位，再以近景进入真正难造的位置。讲丝杠就看螺纹与滚柱关系，讲驱动就看运动传递，讲控制就看反馈路径和接口，不能用同一总览换标题顶替所有镜头。

公司动作清单除clip名，还记解释窗口、原生动作区间、末帧保持、静态区间和各自用途。2秒动作不能自动覆盖随后十几秒解释；合成后检查实际生效帧。可以合理静态讲财务，也可以二维推近，但记录实情，不把重复末帧或二维变换称为持续原生动作。

每个功能近景查看最终编码：标题、标签、卡片、字幕有没有挡住所讲的实体；模型是否出画；零件连线与啮合有没有真的可辨。远景小模型和出画的大模型都要返工。带卡镜头单独构图，不用统一0.64缩放替代镜头设计。

Q-D除原有技术、布局、声音和设备检查，另记视觉变化和重复：哪些原理段需要持续动作，哪个静态停留有目的，镜头是否带来新的观察信息。静态比例不设通用质量阈值，动作越多也不自动越好。

## 模型、材料与画面组织

- 整机先看比例、自然姿态、曲面收口、分件/装配间隙、承力与维护接口。局部看可见齿、轴承、紧固、接线和反馈；没有依据的结构不能靠堆细节填满。
- 针对机位调整灯光目标、尺度、反射和曝光，区分材料。冷色线框、发光和景深是辅助，不能掩盖主体材质贫乏或功能结构不清。
- 芯片近景检查有依据的基板器件/焊盘、过孔、布线区域、标记与边缘连接；裸片/晶圆检查功能分区、不同纹理、划片道及尺度。不是把纹理一律挤压成凸起小方块，也不是用更多细线替代功能分区。原尺寸看细节正确，缩略图看细节组织；不能由封面看点推定正文模型质量。
- 保持系列深色背景、清楚的标题层级、强功能近景和克制信息。不要机械复制第一期金色材质，更不要复制其已废止字幕样式。

## 审核与问题关闭

制作者先自检；复核重新查看实际冻结图与视频，以观众视角寻找主焦点和解释内容。没有独立人选时真实记录self_review，不能把另一次自检改名为独立复审。存在用户明确不满意或已发现的视觉阻断，保留具体帧/区域并返工；不能用技术通过抵消。

本期手机检查豁免只对本次提交有效，不降低本地封面、建模、镜头与声音质量，也不跨期继承。用户要求继续制作或提交，不是美术检查的替代证据。
