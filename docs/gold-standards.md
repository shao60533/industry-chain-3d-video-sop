# 金标与 2026-11 制作升级

2026-11-22。整理 10 月 22 日以后的产业链 3D 视频复盘：哪几条片子被定为后续对照的「金标」，从中学到了什么，以及在选题、开场、口播、运镜、建模、声音和封面上新增的做法。这里只发布可复用的方法和检查办法，不发布原片、工程文件、音色、账号、平台后台数据或个人路径。参数值只作为起点，每期仍以实际画面和实际试听为准。

## 金标：拿什么来对照

金标是已经过完整制作、被采用的成片或封面，用来做同宽、同机位、同类镜头的比较。它规定的是**做到什么程度**，不规定每一期的造型、颜色或时长。比较时写清楚对的是哪一版、哪一个时间点，以及具体保住了什么、退步在哪里；不能只写「对标了金标」。

| 金标 | 对照什么 | 怎样用 |
| --- | --- | --- |
| **液冷整柜重制（运镜与精模金标）** | 一条从整柜进到托盘、冷板、快接、分液器、CDU 的观察路线；冷板叠层、快接阀芯剖面、CDU 双泵等主讲件的功能精度 | 新一期的路线设计、精度分配和三组连贯对照都以它为样板（见下文「运镜」「建模」两节）。学的是方法，不复制它的产品结构或参数。 |
| **光模块首期封面与正片（视觉质量金标）** | 封面的粗体字级与单一焦点；金属、玻璃、板材在同一光下的层次；整机、开盖、内部近景三类产品图 | 封面和代表性正文样片在 200 px 和 390 px 宽并排对照，逐项写观察。旧版的黑底字幕、低位布局和过亮区域不继承。 |
| **开场两例（前 2 秒 / 前 5 秒金标）** | ① 产品与第一个动作在首画面，第 2 秒内开始起盖，随后揭示内部层次；② 3–5 秒纯音乐开场后，旁白顺着画面入题 | 分镜阶段写清首个主体、第一个动作、第一条信息各在第几秒出现，样片用正常速度连看 0–5 秒核对。 |
| **智能戒指精修（换载体精修金标）** | 精细部件放进新载体后，开窗、接触面、刚柔板过渡和板端连接跟着更新 | 把已经验证过的精修方法迁到新产品时，用它检查「配对件、支撑、走线、遮挡、标签」是否一起更新。 |
| **反例：早期人形机器人版本** | 机构做了，但成片镜头离得太远；整机比例和关节轴约束不足 | 作为负面对照保留：模型里有，不等于画面里看得到。 |

金标本身也有记录在案的不足，复用时一起避开：

- 液冷开场 4 秒内有漂亮的合拢，第一条机构解释却到第 12 秒才出现。下一期让第一个可读的动作结果更早出现。
- 液冷中段连续三个短镜只念部件名称，没有给动作。要复用这段语法，先在同一镜头里给出一个动作结果，再移到下一处。
- 重排旧素材时出现过重复源帧和跳帧。插拔、贴合、开阀这类动作先锁成原生连续帧，余下时间放在停稳段调整。

## 一、选题：从大众产品切入，正片讲整机变化

两轮纠正的结论：

1. **第一轮：太专业。** 产业链题目要从观众用过或见过的整机、终端或服务开始，用一个日常动作和一个具体问题，把观众带到决定体验的那个部件，再讲门槛和生意。
2. **第二轮：切入点太小。** 「手机 256G 和 512G 为什么差价大」「快充后段为什么变慢」这类问题只需一个机制就能讲完，适合做开场第一幕或短篇。正片要先选定一个**大众产品的整机或市场变化**（能力、成本或竞争方式变了什么），再沿因果路径追到各供应环节，并核实哪些厂商的产品确实进入了采购。

开工简报必须写出：观众能问出口的那个问题、整机或市场变化、追到的供应环节，以及每一环要拿到的一手证据（公司年报、招股书、官方规格、实测）。标题、封面、首帧和入声首句围绕同一个对象和同一个问题。

## 二、开场：2 / 5 / 20 / 60 秒四个节点

都从成片的第一个画面开始计时；旁白的真实起点另记。

| 节点 | 产品 3D、纯音乐开场 | 有口播的解读 |
| --- | --- | --- |
| **0–2 秒** | 产品或要讲的部位清楚入画，第一个有目的的动作接住封面承诺。主体、尺度、动向都看得清。 | 首画面能认出公司、产品或事件，首句直接落到这个对象上。 |
| **0–5 秒** | 同一主体上出现第一个可读的变化（起盖露出内层、接头脱开），音乐落点和动作对齐。 | 给出一项有内容的进展：直接影响、判断或有证据的反常对照。 |
| **到 20 秒** | 音乐开场结束，第一句旁白顺着最后一个画面入题，开头的问题完整说完。 | 悬念进入第一条证据，问题留出可听的时间，答案和对应画面一起进。 |
| **到 60 秒** | 第一个机制已经讲完，观众知道这期要回答什么、会沿哪条路线走。 | 第一章的判断已经下了，数字有画面支撑。 |

- 产品拆解片默认**纯音乐开场、无字、无旁白**，时长按本期选定（3–10 秒都有用过的例子）。这段只放画面和音乐，不叠标题字。
- 钩子用观众不懂专业指标也能听懂的反差。冷门指标（例如信用利差）放到第一章，先用一小段讲清机制再报数。
- 发布后有平台数据时，按平台原字段记录前 2 秒、前 5 秒的读数、口径、统计窗口和样本量。缺的字段留待核，不从 5 秒读数倒推 2 秒。

## 三、口播稿：说话的样子，坚定的判断

- **口语，不是书面稿。** 短句，一句一件事，数字取整。书面词换成说话用的词。
- **每章一个立场。** 不写「短期守得住、长期会收窄」这类两头说的话。结论用「说白了」「所以」这类口语带出，不贴「判断：」标签。
- **不用转述腔。** 不写「公司自己说」「管理层归因于」，直接陈述事实，来源记在核查表。
- **原因逐个成章。** 先讲对象本身，再把每个原因单独成章展开、自己算账、自己下结论。答案不在开头预告，收在结尾。
- **推断要下得坚定。** 证据不够时先再找一轮，用机制和定性旁证把逻辑撑实，然后直接下判断。口播里不说「这是推断」「证明不了」；哪些是推断、哪些数是转述，记在核查表和待定事项里。
- **通俗但专业。** 用行业本来的说法（估值是收入的多少倍），第一次出现时一句话带过含义，不用小学算术式比喻。
- **结尾给预判，不列「接下来盯什么」清单。**
- **讲到机制。** 例如电便宜的真正原因是「送不出去」，而不只是发电成本低。

交稿前逐章自查三点：结论句是否只有一个立场；有没有转述腔；念出来像不像说话。事实核查照做，不能为了口语化丢掉来源。

## 四、配音：语速、停顿与读法

方法沿用[语义段落配音](speech-production.md)，新增：

- **默认节奏偏紧。** 原速（约 4.4 字/秒）听着拖。被采用的节奏是整段变速 1.12 倍（音高不变），停顿为章节约 0.9 秒、段落约 0.75 秒、句内约 0.32 秒。新一期可以直接从这个节奏起步，再按实听微调；变速范围在 1.00–1.12 之间，不逐句提速，不提到 1.2 倍。
- **停顿只补不叠。** 补停顿 = max(0，目标停顿 − 已有留白)，保留自然呼吸。
- **英文名按原词念。** 英文公司名、产品名按原词写，念纯英文，不用拼读改写，也不用中文音译。缩写按行业习惯逐字母读。
- **新词先出对比片。** 每个新出现的英文词、专名或多音字，先做两三种写法的对比片让使用者挑。转写对了不等于念对了，这一步不能省。
- **每段过听检。** 变速或重录后重新跑 ASR 和听检（漏读、重复、语调、音色），转写只能提示候选问题，不能替代实听。

## 五、运镜：把功能路线变成观众的路线

照液冷金标的做法，分镜先定观众要看懂的路径和状态变化，再写每一镜的起始参照、揭示动作、观察窗口和交接对象。先用低模排通路线，再从实际精模出三组连贯对照：

1. **总装进局部。** 先给局部和整机的关系，经过真实的开口、滑轨或接口进入下一尺度。机械动作分相，内部关系先读清，外壳最后收。上一镜离场和下一镜进场先对齐主体尺寸、朝向和关注点。
2. **局部看机构。** 用闭合、动作中段、功能终态核真实接触。外观先回答部件在哪，剖面再回答为什么能工作；用同一条动作轴保持方向，给关键动作留出观察时间。
3. **局部回总装。** 回去时带上观众已经认得的管、线、支架或元件。讲生意的段落用同一产品作解释背景，画面停下来给数据阅读时间。

慢速线性观察、缓入缓出移动和硬切各有用途，不能把逐段 smoothstep 当成整片丝滑的保证。镜头跟着功能路径走（热、光、电、力从哪来、到哪去），途中保留可定位的结构。

## 六、建模：精度投在配合面和动作

**精度按镜头距离分配。** 机柜、机箱或整机先做可信的支撑、固定和检修结构（立柱、横梁、侧板分片、锁点、把手、接口、通风区，不能是白盒子）。板级按实际位置建功能区、端点、支撑和避让。微距只做主讲的接触面、配合轴、密封和剖面。

**精度投在三件事上：相邻部件怎么装、工作面怎么接、动作时什么在变。** 每个核心近景在分镜上补一行：「参考图或剖面 → 装配基准 → 哪两个面接合 → 动作中段 → 最终机位」。

| 产品类型 | 优先做细 | 用什么画面检验 |
| --- | --- | --- |
| 光模块 / CPO | 壳体与板卡定位、镜筒台阶、真实镜片厚度、光纤端面与固定；光轴开盖后仍在原位 | 同一装配拍整机、开盖、侧剖三种取景 |
| 主板 / 存储 | DIMM 槽空腔、定位键、接触区、锁扣；金手指、M.2 接点与固定端；按用途分区 | 整板 → 插入中间态 → 到位态 → 暗色封装与接点 |
| 晶圆 / 封装 | 阵列、逻辑块、I/O、划片道、边缘不完整图形、定位缺口；焊盘、开窗、层间接点 | 晶圆全景、单颗微距、基板表面、剖面同批出 |
| 光刻 / 设备整机 | 机柜接缝、百叶、把手、状态窗、底板；反射镜支架与三点安装；光束用半透明加色辉光 | 整机闭合 / 开门、核心光路近景；光不能是实心锥体 |
| 机器人 / 运动机构 | 公开外形与关节轴约束比例；电机、减速器、腱绳导向、转轴与接触垫；输出轴承与法兰 | 抓取前、初接触、握稳三个位置核贴合与避让，再切到机构工作面 |
| 光伏等层压产品 | 玻璃边缘厚度、封装层、电池片互连端点、边框槽、接线盒出线 | 正面、边角剖面、背面接线盒，跟着电从电池片走到端子 |

**修之前先找根因。** 同机位先查结构轮廓、位置和闭合；再用生产材质和灯光看黑塑、加工金属、玻璃、焊料能否分辨。装配缺失修几何，已有接触面被高光洗掉修布光或材质，功能面出画先修机位。一次返工只改一类，才能知道哪项改动有效。重复件共用网格；螺纹、触点、开孔是否建实几何，看它是否承担配合、剖切、轮廓或运动遮挡。示意模型解释装配和机制，尺寸、用材和具体方案仍需对应原件核实。

**常见的「看着怪」怎么修：**

- 晶体管、芯片结构：用真实形态（例如 FinFET 鳍片、栅极、接触柱、逐层变粗的金属层），按尺度从近到远过渡，远景用同节距的程序化纹理接上，不用卡通圆柱。
- 光、等离子、激光：用透明加自发光的加色材质，强度随朝向衰减并带少量噪声，不做实心发光体；亮度以不过曝、能看到内部为准。
- 远景放大比喻（例如「把镜面放大到一个国家那么大」）：用暗色抛光面加细网格表达尺度，不用一块平灰板。

## 七、声音：音效不抢音乐，卡点用实测起音

- **音效始终在 BGM 之下。** 在最终混音电平下逐段测量：纯音乐开场段音效至少比音乐低 12 dB，其余段至少低 6 dB。用平滑的增益包络（约 30 ms 起、400 ms 放）自动压住超出的部分。开场提示音用柔和的低音，不用尖锐高频加噪声。
- **卡点用实测鼓点。** 切点取逐个鼓点的实测起音时刻，向下取整到帧，硬切；文字和数字在切点首帧就以最终内容出现，不滚数、不淡入。节拍网格可能比实际鼓点晚，也可能把速度算错，不能直接信。
- **成片解码核对。** 从最终编码取画面帧间差的峰值，与音头比较，画面应早于声音 0–1 帧。波形对齐只是起点，不能代替连续实听。

## 八、字幕与文字通道

- 1080 宽默认 **56 px、单行、透明背景、画面中轴 ±2 px**，每行实际墨迹不超过 672 px；工作流核心仍支持最多两行，单行以拆页替代双行难例。
- 同一时间只保留**一个主要文字通道**：字幕、标签、卡片各自承担不同信息，标签只标部件名，不重复字幕内容。
- 纯音乐开场段不放字。

## 九、封面

- **独立设计，不用带字幕的正文截帧。** 可以另设精模专用机位、用真实来源素材或生成图；生成图保留示意身份，不冒充厂商照片或结构证据。
- **一个主标题，加一句必要的反差或提问。** 主标题通常 1–2 行、副题 1 行，用粗黑体；不把公司清单、目录、章节号搬上封面。
- **一个有理由的视觉主角。** 200 px 宽能认出主体、读出主句、找到唯一看点；金属、玻璃、板材有分层，最暗部位仍可辨。
- **每个频道锁一套品牌规范。** 品牌位置、字体、色板写进本地封面契约（含参考图 SHA），各期只换主体，不重新发明品牌和版式。本仓库不提供任何固定品牌。
- 分别构图需要的比例（常用 3:4 与 9:16 或 4:3），文字放在最小比例的安全窗内；原尺寸逐字核对，再在 200 px 与 390 px 下和金标封面并排看。

## 十、交付与归档

- 每一步给使用者确认：开题 → 全稿 → 小样 → 成片。小样确认后再长渲染。
- 长渲染前确认磁盘空间；渲染进程与会话分离，会话断开不中断。可重渲的帧序列不进归档清单，删除前先问使用者。
- 归档写制作记录和 `SHA256SUMS`，逐个核对；需要传到远端存储时传完核对两端哈希。

## 与 12 项报告的关系

不新增第 13 项报告。上述观察分别落在既有项目里：开场节点进开场节奏报告；运镜进 `dynamic_playback`；建模精度进 `model_coverage` 与 `product_realism_states`；字幕与文字通道进 `layout_geometry`；配音节奏、读法与音效电平进 `voice_music_listening`；封面进 `cover_crop` 的五项观察。自动核心只核文件、身份、覆盖与版本依赖，真实画面、声音和连续播放仍需实际观察，没有能力实看的保持 pending。
