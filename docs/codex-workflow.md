# 用 Codex 执行完整视频工作流

Codex 作为主执行者，维护一个 job 的来源、稿件、分镜、模型、音轨、渲染和质量证据。Blender、配音、对齐、合成和发布工具执行具体操作；其他模型按需接入。每次交接以当前文件及哈希为准。

## 角色与权限

| 角色 | 负责什么 | 需要保留的边界 |
|---|---|---|
| 使用者 | 指定来源、选题、品牌、接受选择和实际发布范围 | 制作指令与对外发布分别授权；已有授权在原范围内有效 |
| Codex | 拆解任务、读源、写稿、分镜、建模脚本、工具调度、修复与证据归档 | 自检写 self_review；不补造用户确认、实听、设备或发布回执 |
| 专业工具 | 建模、渲染、配音、对齐、视频合成、探测与平台操作 | 工具能力和实际输出逐项验证，固定接口名不等于已安装 |
| 实际复核者 | 读稿、看图、听看连续成片、检查真实设备 | 记录身份、能力、检查范围和当前资产哈希 |

## 可直接交给 Codex 的启动任务

```text
请按本仓库 AGENTS.md、制作 SOP 和验收规则，作为主执行者制作一期产业链 3D 视频。

本期产品：[产品]
完整来源：[本地文件或可访问的指定完整原文]
来源版本与数据日期：[版本/日期]
工作目录：[新的本地 job 目录]
品牌问候：[自有品牌问候]
配音：[获授权音色或本地参考；不上传个人音频到未授权目的地]
画幅/时长：[默认 1080×1920、24fps，约5分钟，按实际旁白决定拆集]
工具：[实际可用的建模、配音、对齐、合成工具；缺失如实列出]
模式：produce_only

先检查缺口、读完整来源、建立 job；写一层完整判断和全期结构。
再做配音试听、三类参考图、真实展开/环绕/合体与音乐开场，以及正文难例样片。
沿用已经接受的选择，不扩大确认或发布范围。
每阶段提供可审阅产物、实际证据、未验范围与下一步。
未经实际检查的状态保持 pending；所有本地私人信息、密钥与音色不进入公开仓库。
```

## 每阶段的工作顺序

1. **建立任务。** 复制空白模板，锁完整来源版本与 SHA，列集数、预算、缺口和实际工具。
2. **稿件和分镜。** 按用途→作用→工艺/门槛→瓶颈→公司竞争→盈利推进；问题 ID 与结尾答案及画面一一对应。
3. **小样验证。** 先做30–60秒配音、整体/展开/内部图、开场和正文难例。结构与装配不成立时先改几何；字幕难例先验字形与同屏焦点。
4. **实现和调度。** Codex 编写或修复具体工具脚本，依赖与路径参数化；记录相机、材质、对象语义 ID、动作和音频 cue。保存重开验收后再渲染。
5. **成片与证据。** 抽帧、解码、实际字形/focus 日志和哈希由工具产生；声音、连续动作和设备 UI 按实际能力检查。缺证据保持待验审阅包。
6. **冻结和交付。** 更新 manifest 与全部依赖，区分技术通过、布局通过、release_ready 和实际发布状态；只重验受改动影响的部分。
7. **授权发布。** Codex 调度具体平台适配器，上传前和提交前再核质量、账号、冻结内容与授权；未知结果只读恢复。

## 工作目录

```text
jobs/<job-id>/                 # 本地目录，默认忽略，不推送公开仓库
  job.json
  A-reference/                # 完整来源、版本、来源映射
  B-script/                   # 确认稿、TXT/JSON、公司判断
  C-design/                   # 参考、设计锁、分镜、字体/profile
  D-audio/                    # 试听、音轨、timing、字幕
  E-model/                    # 原生模型、语义节点、动作小样
  F-film/                     # 当前成片、全帧日志与技术报告
  G-package/                  # spec、12项报告、冻结发布资产
  H-publish/                  # 授权、manifest、attempt/result、归档
```

## 工具与现实检查

文档中的原内部 Python 程序和 xhs_video_* 名称没有随仓库分发。Codex 可以对接你实际提供的工具或实现适配器；不能把 SOP 变成虚构的可执行命令。具体职责见[工具适配说明](tool-adapters.md)。

Codex 能否实听、连续观看或控制实际设备，取决于当前会话能力。仅有文字和静帧时，声音与动态检查由有相应能力的复核者完成。设备截图、原音轨、后台回执保存在本地 job；公开展示只选经检查的纯产品渲染。
